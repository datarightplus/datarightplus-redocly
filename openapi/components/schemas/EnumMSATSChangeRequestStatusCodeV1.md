**MSATS Change Request Status Codes**

MSATS Change Request Status Codes as sourced from the MSATS Technical Guide description for [Change Requests](https://visualisations.aemo.com.au/aemo/web-help/Content/MSATSTechnicalGuide/Change_requests.htm)

| Code | Description        | Notes                                                                                                                                                                                                                                                                                                                                                              |
|------|--------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PVAL | Pending Validation | The Transaction passed Checksum Validation. <br />If the change request is awaiting missing data, MSATS updates the Proposed Change Date and Initiator when it receives the missing data                                                                                                                                                                           |
| REQ  | Requested          | MSATS has sent Notifications.<br />MSATS has all data required to initiate the Transaction                                                                                                                                                                                                                                                                         |
| PEND | Pending            | The Transaction has passed the objection period and is either:<br /><ul><li>Awaiting final details before it can complete</li><li>Awaiting arrival of the Proposed Change Date</li></ul>                                                                                                                                                                           |
| OBJ  | Objected           | MSATS has received an objection and the transfer is suspended until the Objection is either: <br /><ul><li>Withdrawn</li><li>The objection period lapses (MSATS cancels the Change Request)</li></ul>                                                                                                                                                              |
| CAN  | Cancelled          | Cancellation reasons: <br /><ul><li>The proposed new retailer is deregistered as a result of a RoLR event (the RoLR process cancels in-progress Change Requests for that Retailer)</li><li>A nominated number of days have passed since MSATS received Objections and they are not withdrawn</li><li>The initiator of the Change Request has withdrawn it</li></ul> |
| COM  | Completed          | Completion reasons:<br /><ul><li>There are no outstanding Objections</li><li>The Proposed Change Date is either reached or passed</li><li>All data MSATS was awaiting, e.g. an Actual Change Date from an MDP is delivered</li>                                                                                                                                    |
| REJ  | Rejected           | Rejection reasons: <br /><ul><li>Does not pass all validation rules</li></ul>                                                                                                                                                                                                                                                                                      |
